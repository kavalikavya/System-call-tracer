k# System Call Tracer and Visualizer

## Operating Systems Mini Project

A web-based system call tracing and visualization tool that traces system calls made by sample programs and visually demonstrates the transition between user mode and kernel mode.

---

## 1. Abstract

System calls provide the interface between user applications and the operating system kernel. Applications use system calls to request services such as file access, memory management, process creation, and input/output operations.

The **System Call Tracer and Visualizer** is an educational web application that traces system calls made by sample programs using Linux `strace` and presents the collected information through an interactive dashboard.

The system displays system-call statistics, categories, execution time, process information, process hierarchy, system-call timelines, return values, and user-mode/kernel-mode transitions.

The project helps students understand how applications interact with the operating system through system calls.

---

## 2. Problem Statement

System calls are an important part of Operating Systems, but their execution is difficult to observe directly.

Traditional command-line tracing tools provide raw text output, which can be difficult for beginners to understand.

Therefore, this project aims to develop a visual tool that:

- Captures system calls from sample programs
- Organizes system calls into meaningful categories
- Displays system-call execution information
- Visualizes user-mode and kernel-mode transitions
- Shows process relationships
- Provides an interactive timeline for system-call events

---

## 3. Objectives

The main objectives of the project are:

1. Trace system calls generated by sample programs.
2. Analyze system-call names, timestamps, durations, arguments, and return values.
3. Categorize system calls into groups such as File, I/O, Memory, and Process.
4. Visualize user-mode to kernel-mode transitions.
5. Display parent-child process relationships.
6. Provide an interactive system-call timeline.
7. Allow users to filter system calls by category.
8. Present the results through a simple and user-friendly web interface.

---

## 4. Key Features

### System Call Tracing

The application uses Linux `strace` to capture system calls generated by sample programs.

### System Call Statistics

The dashboard displays:

- Total system calls
- Unique system calls
- Trace execution time
- Wall-clock execution time

### System Call Categories

System calls are classified into categories including:

- File
- I/O
- Memory
- Process
- Network
- Security
- Time
- System
- Other

### Top System Calls

The dashboard displays frequently occurring system calls using visual bars.
