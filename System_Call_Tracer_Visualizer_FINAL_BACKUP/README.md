# System Call Tracer & Visualizer

An Operating Systems mini-project that traces system calls generated by safe, predefined sample programs and visualizes the results in a web dashboard.

## Approved project alignment
Project No. 2 in the supplied OS Mini Project Guide:
"System Call Tracer and Visualizer" — trace system calls issued by a sample program and visualize user-mode/kernel-mode transitions.

## Features
- Select from safe predefined sample programs
- Run a trace using Linux `strace`
- Display total system calls
- Show unique system-call count
- Show total execution time
- Show top system calls
- Show system-call table with count and percentage
- Show a simple User Mode -> System Call -> Kernel Mode -> User Mode visualization
- Store the latest trace in memory only
- No database required

## Technology
- Python 3
- Flask
- Linux `strace`
- HTML5
- CSS3
- Vanilla JavaScript
- No frontend framework
- No database

## Important
This project must run in Linux/WSL because `strace` is a Linux utility.

### Ubuntu / WSL setup
```bash
sudo apt update
sudo apt install strace python3 python3-pip
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open:
http://127.0.0.1:5000

## Demo
1. Select "File Reader"
2. Click "Trace Program"
3. Wait for results
4. Explain the dashboard
5. Show the call table and top-call bars
6. Explain User Mode -> Kernel Mode -> User Mode

## Viva safety
Only predefined sample programs are executed. Do not add a feature that accepts arbitrary shell commands from the browser.

## Project limitations
- The exact system-call list depends on the Linux distribution and Python runtime.
- This is a learning simulator/visualizer, not a replacement for professional tracing tools.
- User/kernel transition is represented conceptually in the dashboard; the trace itself is based on observed system calls.
